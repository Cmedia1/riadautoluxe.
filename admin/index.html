Créer votre token GitHub

  1. Sur GitHub : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate new token, donnez-lui un nom, et choisissez Only select repositories → sélectionnez le dépôt de ce site.
  3. Sous Repository permissions, réglez Contents sur Read and write.
  4. Générez, copiez le token (il ne sera montré qu'une fois) et collez-le ci-contre.

Ce token n'est envoyé qu'à l'API officielle de GitHub, jamais ailleurs. Ne le partagez avec personne.

Sans token GitHub

Téléchargez les fichiers modifiés et déposez-les manuellement dans votre dépôt via l'interface web de GitHub (glisser-déposer dans le dossier assets/data/, en écrasant les fichiers existants).
